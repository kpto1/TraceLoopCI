# Chinese customer-service examples

Run `python examples/golden-cases/import.py`. TRACELOOP_URL defaults to http://localhost:8000; TRACELOOP_API_KEY defaults to the local demo key. TRACELOOP_DATASET is a dataset name, not an integer ID. The script creates or locates that name and uses the returned server ID. Repeated imports skip existing input_text values.

These are example assertions, not validated labels or evidence of real model quality. Review rules against your own business policy before use.
